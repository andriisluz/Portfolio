# Portfolio

## 1. Effektive Kommunikation mithilfe von Markdown

In dieser Unterrichtseinheit habe ich folgendes gelernt: 

- Wie erstellt man Markdown Dateien in GitHub
- Was ist Markdown
- Erste Stile
  1. Heading `# H1`
  2. List `- Item`
  3. Link `[Google](https://google.com)`
  4. Bild `![Cat](https://www.svgrepo.com/show/522779/cat.svg)`
  5. Code Snippet ``` `Code hier` ```
  6. Mentions ` @bob `
  7. Bezug auf Pull Request oder Issue `#123`
  8. Kontrollkästchen ` [ ] ` oder ` [x] `
  9. Zitat ` > Hier ist ein Zitat `
